## 💳 СПОСОБ 1: Обновление через веб-интерфейс (РЕКОМЕНДУЕМЫЙ)

### Шаг 1: Открой Vercel Dashboard
```
https://vercel.com/dashboard
```

### Шаг 2: Перейди в Settings
- В правом углу нажми **⚙️ Settings**
- Или выбери проект → **Settings**

### Шаг 3: Перейди в Billing
- Левая панель → **Billing**
- Вкладка → **Plan**

### Шаг 4: Upgrade to Pro
```
[Upgrade to Pro] ← нажми эту кнопку
```

### Шаг 5: Подтверди платеж
- Введи карту
- Нажми **Subscribe** ($20/месяц)
- Подтверди платеж

### Шаг 6: Проверь обновление
```
Plan: Pro ✓
Serverless Functions: Unlimited ✓
```

## 🔄 СПОСОБ 2: Обновление через Vercel CLI

```bash
# Установи Vercel CLI (если не установлен)
npm i -g vercel

# Авторизуйся
vercel login

# Обновись на Pro
vercel upgrade

# Следуй инструкциям в консоли
```

## 🚀 ПЕРЕРАЗВЕРТЫВАНИЕ ПРОЕКТА

### После обновления тарифа:

#### Способ 1: Через веб-интерфейс
1. Открой https://vercel.com/dashboard
2. Выбери проект **nerv-telegram-bot-vercel**
3. Нажми **Deployments** вверху
4. Найди последний деплой
5. Нажми **...** → **Redeploy**
6. Выбери **Production**
7. Жди завершения ✓

#### Способ 2: Через Git push
```bash
git push origin main
# Vercel автоматически пересоберет и перезагрузит
```

#### Способ 3: Через Vercel CLI
```bash
vercel --prod --yes
```

## ✅ ПРОВЕРКА ПОСЛЕ ОБНОВЛЕНИЯ

### В Vercel Dashboard:
1. Перейди на проект
2. Откройся **Deployments**
3. Проверь статус последнего деплоя
4. Должно быть: ✅ **Ready** (не ❌ Failed)

### В консоли браузера:
1. Открой бота в Telegram
2. Жми любую кнопку
3. Открой **DevTools** (F12)
4. Вкладка **Network**
5. Проверь что запросы идут успешно (200 OK)

### API функции:
```bash
# Проверь все endpoints работают:
curl https://nerv-telegram-bot-vercel.vercel.app/api/app-auth
curl https://nerv-telegram-bot-vercel.vercel.app/api/app-tasks
curl https://nerv-telegram-bot-vercel.vercel.app/api/analytics
```
